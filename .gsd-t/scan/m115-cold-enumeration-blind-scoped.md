# Test-Plan Enumeration — v1.27 Rate Ledger + Team Member Deactivation

**Area under test:** the feature area headed `## v1.27 — Rate Ledger + Team Member Deactivation` in `requirements.md:545-570` (REQ-A6, REQ-A7, REQ-A10, REQ-A11, REQ-B4.2, plus the task-level paragraph at `requirements.md:559-566` naming RULE-RL-3 and RULE-RL-5, the history tooltip, the set-rate dialog, the edit-date dialog, and the parallel `deactivation-consumers-and-traps` domain).

Where the answer plainly lives in one of them, the row is a `GAP` naming which document holds it — that is a real finding about this requirements file, which states outcomes ("complete") without stating the rules the outcomes were judged against.

**Terms glossed once.** *Rate Ledger* — the screen listing each team member's money figures. *Cost* — what a person costs the company per hour. *Billing Rate* — the default hourly figure charged to a client for that person. *Client column / override* — a per-client hourly figure that replaces the default for that client. *Never-billed* — a person marked as never charged to any client. *Dated ledger* — rates carry a start date, so an invoice for an old month resolves the rate that was in force then. *Deactivation* — retiring a team member without deleting them. *Endpoint* — the address the server answers requests at, which a caller can reach directly without going through the screen.
